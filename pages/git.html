Wprowadzenie

Git to rozproszony system kontroli wersji. Zapamiętuje historię zmian w projekcie w postaci commitów, a GitHub pozwala przechowywać repozytorium online i współpracować przez Pull Requesty.

Zanim zaczniesz nową zmianę, zawsze zsynchronizuj lokalny main z repozytorium zdalnym.

Najważniejsze polecenia

Podstawowe polecenia Git
Polecenie Przykład Opis
git clone git clone URL Pobiera kopię zdalnego repozytorium na komputer.
git status git status Pokazuje stan repozytorium: zmienione, dodane i nieśledzone pliki.
git add git add index.html Dodaje zmiany do poczekalni (staging area).
git commit git commit -m "feat: opis" Zapisuje zmiany z poczekalni jako nowy commit.
git push git push -u origin nazwa-brancha Wysyła lokalne commity do repozytorium zdalnego.
git pull git pull --ff-only origin main Pobiera i scala zmiany z repozytorium zdalnego.
git fetch git fetch origin Pobiera informacje o zmianach zdalnych bez scalania ich.
git branch git branch -a Wyświetla listę gałęzi lokalnych i zdalnych.
git switch git switch -c feature/nowa Przełącza gałąź; z opcją -c tworzy nową.
git log git log --oneline -5 Wyświetla historię commitów.

Procedura pracy na branchu

  1. Synchronizacja – git switch main i git pull --ff-only origin main.
  2. Branch – git switch -c feature/nazwa-zmiany.
  3. Zmiana – edytuj pliki i sprawdź je poleceniem git status.
  4. Commit – git add plik i git commit -m "opis".
  5. Push – git push -u origin feature/nazwa-zmiany.
  6. Pull Request – otwórz PR na GitHubie, poproś o review i po akceptacji scal go do main.
