Wprowadzenie

.NET CLI to narzędzie wiersza poleceń dotnet, które pozwala tworzyć projekty, pobierać zależności, kompilować i uruchamiać aplikacje bez otwierania IDE.

Polecenia projektu, takie jak build czy run, wykonuj w katalogu, w którym znajduje się plik .csproj.

Najważniejsze polecenia

Podstawowe polecenia .NET CLI
Polecenie Przykład Opis
dotnet --version dotnet --version Wyświetla wersję używanego SDK.
dotnet --list-sdks dotnet --list-sdks Wyświetla wszystkie zainstalowane wersje SDK.
dotnet new list dotnet new list Pokazuje dostępne szablony projektów.
dotnet new console dotnet new console -o HelloApp Tworzy nową aplikację konsolową w podanym katalogu.
dotnet restore dotnet restore Pobiera zależności (pakiety NuGet) projektu.
dotnet build dotnet build Kompiluje projekt i zgłasza błędy kompilacji.
dotnet run dotnet run Buduje projekt (jeśli trzeba) i uruchamia aplikację.
dotnet clean dotnet clean Usuwa pliki wynikowe poprzedniej kompilacji.

Od zera do działającej aplikacji

Kompletna sekwencja utworzenia i uruchomienia aplikacji konsolowej:

dotnet --version
dotnet new console -o HelloApp
cd HelloApp
dotnet restore
dotnet build
dotnet run
dotnet clean
